DirectX 11을 이용해 간단한 엔진을 만드는 것을 목표로 하는 프로젝트입니다.  

[![Title](https://img.youtube.com/vi/WVNjKpz2Svk/0.jpg)](https://youtu.be/WVNjKpz2Svk)  
(클릭 시 유튜브 동영상을 재생합니다.)

주요 특징은 다음과 같습니다.
- 리플렉션에 기반한 에디터 편집, PIE 기능들.
- JoltPhysics를 이용한 물리 시뮬레이션
- 디퍼드 렌더링, 스크린 스페이스 엠비언트 오클루젼(SSAO), Emissive, GPU Particle
- Cascade Shadow, Normal Offet Bais Shadow Mapping
- FBX SDK를 이용하여 3D 모델링 로드, 애니메이션 재생
- RapidJson 라이브러리를 이용하여 Asset Json Serailize
- Effect 프레임워크가 아닌 HLSL 리플렉션 직접 구현
